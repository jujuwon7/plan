# 2026-10-13 연구 기록

## 오늘 한 일

- 우수민 교수님의 자문을 바탕으로 첫 연구 단계를 다시 정리했다.
- 첫 단계는 실제 노선 분석이나 최적화가 아니라, 충전 대기와 출발 지연의 계산이 맞는지 확인하는 독립 실험으로 정했다.
- 버스 3대가 각각 두 회차를 수행하며 공유 충전기를 사용하는 합성 시나리오를 구현했다.
- 도착 순서 방식(FCFS), 다음 출발시간 우선 방식과 충전기 2대 조건을 비교했다.
- 입력 CSV, 결과 CSV·JSON, 계산 코드, 테스트와 시뮬레이션 재생 화면을 하나의 실험 폴더로 구성했다.
- 원본 DTUMOS Energy 코드는 수정하지 않고 결과를 별도 HTML 화면과 DTUMOS 형식의 재생 화면에서 볼 수 있게 했다.
- 충전기 전력과 전력량, 충전 대기와 출발 지연, 현재 버스 상태의 차이를 정리했다.
- 향후 실제 노선 사례 후보로 양천운수 602번을 검토했지만, 현재 결과에는 실제 602번 운행자료를 사용하지 않았다.

## 실험 설정

- 버스: B1, B2, B3
- 회차: 차량별 2회
- 충전 장소: 가상 차고지 1곳
- 충전기: 1대 또는 2대
- 충전기 출력: 60 kW
- 충전효율: 계산 검증을 위해 100%로 단순화
- 충전 방식: 한 번 충전을 시작하면 필요한 충전량을 모두 채우는 방식
- 비교 정책: FCFS와 다음 예정 출발시간 우선
- 시간: 실제 시각이 아닌 시뮬레이션 시작 후 경과분

B1과 B2는 같은 시각에 도착하도록 만들고, FCFS에서는 입력 순서에 따라 B1을 먼저 선택하도록 정했다. 서로 다른 예정 출발시간과 충전시간을 주어 두 충전 정책이 다른 결정을 내리는지 손으로도 검산할 수 있게 했다.

## 계산 기준

```text
충전시간 = 필요 충전량 / (충전기 출력 × 충전효율) × 60
충전 대기시간 = 충전 시작시각 - 실제 도착시각
실제 출발시각 = max(예정 출발시각, 충전 종료시각)
출발 지연시간 = max(0, 실제 출발시각 - 예정 출발시각)
```

첫 회차에서 생긴 출발 지연은 같은 차량의 다음 회차 도착에도 전달한다. 현재는 교통상황이나 회복운행을 반영하지 않으므로 발생한 지연은 충전과 충전 대기에서 시작된 것으로 해석한다.

## 나온 결과

| 조건 | 평균 충전 대기 | 전체 출발 지연 | 정시 출발률 |
|---|---:|---:|---:|
| 충전기 1대·FCFS | 17.50분 | 120분 | 33.3% |
| 충전기 1대·출발시간 우선 | 8.33분 | 40분 | 66.7% |
| 충전기 2대·FCFS | 1.67분 | 0분 | 100% |

`120분`, `40분`, `0분`은 충전 대기시간이 아니라 6개 출발 이벤트의 지연을 합한 값이다. 충전기 2대 조건에서도 B3는 10분을 기다리지만 예정 출발 전에 충전을 마쳐 출발 지연은 발생하지 않는다.

FCFS에서는 첫 회차 지연이 다음 회차 도착에 전달되고 다시 충전 대기를 만나면서 지연이 커졌다. 출발시간 우선 방식에서는 출발이 급한 차량을 먼저 처리하여 현재 합성 조건에서 지연 전파가 줄었다. 다만 이 결과만으로 출발시간 우선 방식이 항상 우수하다고 결론 내릴 수는 없다.

## 검증한 내용

- 충전기 동시 사용 한도를 넘지 않는지
- 충전시간 계산식이 맞는지
- 대기시간과 출발 지연이 음수가 되지 않는지
- 충전 대기와 출발 지연을 서로 다르게 계산하는지
- 첫 회차 지연이 다음 회차 도착에 전달되는지
- 잘못된 입력을 명확한 오류로 처리하는지
- HTML 화면이 세 시나리오와 세 차량을 모두 포함하는지
- DTUMOS 형식으로 변환한 재생 결과가 화면 계약을 따르는지

총 13개 테스트가 모두 통과했다.

## 화면에서 확인한 상태

- 도착 전: 아직 차고지에 도착하지 않음
- 충전 대기: 차고지에 도착했지만 충전기가 사용 중임
- 충전 중: 충전기를 사용하고 있음
- 출발시각 대기: 충전은 끝났지만 예정 출발시각이 아직 되지 않음
- 운행 중: 실제 출발 후 다음 운행을 수행하는 상태
- 운행 완료 표시: 실제 전체 운행 종료가 아니라 현재 모형에 다음 충전 회차가 없다는 의미

## 현재 단계에서 알 수 있는 것

- 충전순서에 따라 대기시간과 출발 지연이 달라질 수 있다.
- 충전 대기가 있어도 예정 출발 전에 충전이 끝나면 출발 지연은 발생하지 않는다.
- 한 회차의 충전 지연이 같은 차량의 뒤 회차에 전달될 수 있다.
- 충전기 수를 바꾸었을 때 대기열과 지연 계산이 다르게 작동한다.

## 아직 알 수 없는 것

- 실제 양천운수 602번의 충전 대기시간과 출발 지연
- 실제 필요한 충전기 수
- 실제 차량 SOC, 전력소비량과 충전 기록
- 실제 교통상황에서 생기는 운행시간과 배차간격 변화
- 출발시간 우선 방식이 다양한 조건에서도 항상 좋은지

현재 실험은 실제 운영 예측이나 DTUMOS 노선 운행 결과가 아니다. 가상 도착·출발·충전량을 입력한 독립 충전대기 계산 검증이다.

## DTUMOS와의 관계

현재 작은 실험은 충전순서, 대기시간과 출발 지연을 계산한다. 이후 DTUMOS는 실제 노선 이동을 바탕으로 차량의 차고지 도착시각을 만들고, 충전 때문에 변경된 출발시각이 다음 노선 운행과 배차간격에 어떤 영향을 주는지 확인하는 데 사용한다.

```text
노선·시간표
→ DTUMOS 차량 운행과 차고지 도착
→ 충전 모듈의 대기·충전·실제 출발 계산
→ 변경된 시각으로 다음 DTUMOS 운행
→ 후속 도착지연과 배차간격 확인
```
